## ✨ Highlights & Features

* **Flutter 3.47.1 & Dart 3.13.1** — Modern, high-performance cross-platform codebase.
* **WebAssembly (Wasm)** — Multi-threaded CanvasKit web rendering with COOP/COEP headers.
* **Swift Package Manager (SPM)** — Native Apple dependency management (Zero CocoaPods).
* **Google Analytics 4 (GA4)** — Real-time event telemetry and interaction tracking.
* **Live Visitor Counter** — Real-time on-screen traffic badge with active session indicator.
* **Particle Canvas Background** — Interactive dynamic particle network reacting to touch & themes.
* **Adaptive Glassmorphism** — Sleek dark/light modes with responsive multi-screen layouts.
* **BLoC Architecture** — Reactive state management (`ThemeBloc`, `PortfolioBloc`, `HomeBloc`).
* **CI/CD Pipelines** — Automated PR previews, production deploys, and test validation.

## 🚀 Quick Start

```bash
# Get dependencies
flutter pub get

# Run locally in WebAssembly (Wasm) mode
flutter run -d chrome --wasm

# Run test suite
flutter test

# Build production WebAssembly bundle
flutter build web --release --wasm
```
